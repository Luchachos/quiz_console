Telegram Quiz Bot (Викторина)

Это телеграм-бот для проведения викторины. Бот задает вопросы, принимает ответы, начисляет баллы (в зависимости от попытки) и сохраняет рекорды игроков в таблицу лидеров.

Возможности
  Игра в викторину с вариантами ответов.
  Начисление очков: 10 (с 1-й попытки), 5 (со 2-й), 0 (с 3-й).
  Сохранение личных рекордов в файл `records.txt`.
  Вывод Топ-10 игроков по команде `рейтинг` или `/top`.
  Асинхронная обработка сообщений (Long Polling).
